## 📌 Descripción del Proyecto

Esta práctica está diseñada para dominar la lógica de programación en **JavaScript moderno (ES6+)**. La aplicación permite simular un cotizador de seguros de automóviles donde el usuario interactúa introduciendo datos clave (como el modelo y el año) para obtener un presupuesto detallado de manera instantánea y visualmente atractiva.

---

## ✨ Características Principales

| Característica | Descripción |
| :--- | :--- |
| 🧮 **Cálculo Dinámico** | Algoritmo basado en la antigüedad del vehículo, la marca y el tipo de póliza seleccionada. |
| 🛡️ **Tipos de Cobertura** | Opciones de seguro *Básico* (incremento del 30%) y *Completo* (incremento del 50%). |
| ⚡ **Experiencia de Usuario (UI)** | Incorpora un simulador de carga (*spinner*) para dar una respuesta fluida y realista. |
| ⚠️ **Validación de Formularios** | Sistema de alertas dinámicas que evita el envío de datos incompletos. |

---

## 🛠️ Tecnologías y Herramientas

* **HTML5:** Estructura semántica de la interfaz de usuario.
* **CSS3:** Diseño responsivo, limpio y moderno.
* **JavaScript (ES6+):** Funciones modularizadas, Clases (POO), manejo del DOM y eventos.
