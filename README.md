Cotizador de Seguros de Autos 🚗💨

Práctica de JavaScript enfocada en el uso y aplicación de funciones, objetos, manipulación del DOM y buenas prácticas de programación para calcular el costo de un seguro de auto en tiempo real.

📋 Descripción del Proyecto

Esta aplicación web permite a los usuarios calcular el precio estimado de una póliza de seguro de automóvil seleccionando diferentes variables como la marca del vehículo, el año de fabricación y el tipo de cobertura deseada (básica o completa). El proyecto está diseñado para poner a prueba y consolidar conceptos clave de JavaScript moderno.

🚀 Características Principales

Cálculo Dinámico: Utiliza funciones modularizadas para procesar las reglas de negocio y calcular el costo base según la marca y la antigüedad del auto.

Modificadores de Cobertura: Permite elegir entre seguro básico (incrementa el costo un 30%) y seguro completo (incrementa el costo un 50%).

Interfaz Interactiva (DOM): Muestra los resultados de manera limpia en la interfaz, incluyendo un spinner de carga simulado para mejorar la experiencia de usuario.

Validación de Formularios: Asegura que todos los campos estén completos antes de realizar el cálculo, mostrando alertas en caso de error.

🛠️ Tecnologías Utilizadas

HTML5 para la estructura de la interfaz.

CSS3 (con diseño moderno y adaptable) para los estilos.

JavaScript (ES6+) para la lógica de programación, funciones, objetos y manipulación del DOM.
